# Privacy — Apollo II

Apollo II is an **offline-first** local music player.

## Data collected by the app
- Music library metadata and file URIs you grant via Storage Access Framework / MediaStore  
- Playback preferences, playlists, theme/visualizer settings (on-device)  
- Optional AcoustID application API key if you enter one for future ECHOHUNT (stored in private app prefs)

## Data not collected
- No analytics SDK by default  
- No account required for core playback  
- No upload of your music library in the current beta

## Android Auto
Uses the Android media session / browser APIs on your device and car head unit. Music stays on the phone unless you choose external storage you control.
