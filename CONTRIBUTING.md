# Contributing

1. Fork / branch from `release/apollo-ii-v1-beta` or `master` as appropriate.
2. Keep PRs focused; do not commit APKs, keystores, or secrets.
3. Run `./gradlew :app:assembleDebug` and unit tests before opening a PR.
4. Document new visualizer modes in the catalog + background policy.
5. Be honest about test coverage (device vs simulator).
