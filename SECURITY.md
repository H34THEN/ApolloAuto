# Security Policy

## Reporting
Open a private security advisory or email the maintainer via GitHub if you find a vulnerability.

## Secrets
- Never commit keystores, API keys, or passwords.
- AcoustID application API keys belong in on-device Settings prefs only.
- MusicBrainz account passwords must never be stored in the app.

## Sideloading
APK contents are extractable. Do not embed privileged credentials in builds.
